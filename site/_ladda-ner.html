Ladda ner

Bjarbys kundkoll är en nativ macOS-app. Den kräver macOS 26 och en Mac med Apple Silicon.

Ladda ner version VERSION (zip, cirka STORLEK) Alla versioner på GitHub

Första starten

  1. Packa upp och flytta. Dra Bjarbys kundkoll.app till Program.
  2. Öppna med högerklick första gången. Appen är signerad med Developer ID men inte notariserad hos Apple. Högerklicka på appen, välj Öppna, och bekräfta. Därefter startar den som vanligt.
  3. Ge behörigheter. Mikrofon och Skärminspelning krävs — det senare för datorljudet, ScreenCaptureKit fångar bara ljud och ingen bild sparas. Kalender, Kontakter och Automatisering för Mail är frivilliga; utan dem syns inga möten, kontakter eller mejl.
  4. Sätt upp kringtjänsterna. Transkriberingen behöver whisper.cpp med KB-Whisper-modellerna, och röstanalysen en Pythonmiljö. Se installationssidan. Fliken Diagnos under ⌘, säger vad som finns och vad som saknas.
  5. Välj modell för chatten. Under ⌘, väljer du var språkmodellen körs och lägger in en nyckel, eller pekar på en lokal server.

Vad som ingår

I appenInspelning, livetranskribering, arkivpass, röstanalys, kunskapsbank och sökning, chatt, tavla, brief, tidslogg, Obsidian-valv.
Installeras separatwhisper.cpp med KB-Whisper (svensk transkribering), Pythonmiljö med pyannote och speechbrain (röster), Ollama (insikter under samtal och betydelsesökning), Claude Code (kopplade mappar). Alla frivilliga utom whisper.cpp.
KostarIngenting. Väljer du en molnmodell för chatten betalar du den leverantören per anrop.

Bygga själv

Källkoden ligger på GitHub. Xcode behövs inte, Command Line Tools räcker:

git clone https://github.com/fltman/kundkoll.git
cd kundkoll
./scripts/bygg-app.sh        # dist/Bjarbys kundkoll.app

Med ett eget Developer ID-certifikat i KUNDKOLL_SIGNERING minns macOS behörigheterna mellan ombyggen. Utan signeras appen ad hoc.
