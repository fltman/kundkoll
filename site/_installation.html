Installation av kringtjänsterna

Appen gör själva arbetet lokalt, och lånar tre saker från datorn: whisper.cpp för transkriberingen, en Pythonmiljö för rösterna och Ollama för insikter och betydelsesökning. Här är hur de sätts upp. Fliken Diagnos under ⌘, i appen säger vad som finns och vad som fattas.

1. whisper.cpp med KB-Whisper — krävs

Transkriberingen körs med whisper.cpp och Kungliga bibliotekets svenska modeller. Uppmätt slår KB-Whisper medium OpenAIs large-v3-turbo på svenska, trots att den är mindre.

git clone https://github.com/ggml-org/whisper.cpp ~/Projekt/whisper.cpp
cd ~/Projekt/whisper.cpp
cmake -B build -DGGML_METAL=ON && cmake --build build -j --config Release

# Modellerna: KB-Whisper i ggml-format, och Silero för taldetekteringen
cd models
curl -L -o kb_whisper_ggml_small.bin  https://huggingface.co/KBLab/kb-whisper-small/resolve/main/ggml-model.bin
curl -L -o kb_whisper_ggml_medium.bin https://huggingface.co/KBLab/kb-whisper-medium/resolve/main/ggml-model.bin
curl -L -o ggml-silero-v5.1.2.bin     https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin

Standardvägen är ~/Projekt/whisper.cpp. Ligger den någon annanstans pekar du ut mappen under ⌘, → Transkribering. Appen behöver build/bin/whisper-server, build/bin/whisper-cli och de tre modellfilerna i models/.

Taldetekteringen är inte valfri. Utan Silero hittar whisper på text ur tystnad — «Tack.» ur fem sekunder tystnad är uppmätt. Appen har tre lager till mot det, men modellen ska finnas.

2. Pythonmiljö för röstanalysen — rekommenderas

Motpartens röster delas upp av pyannote och känns igen med ECAPA-avtryck från speechbrain. Båda körs i en Pythonprocess som appen startar.

python3 -m venv ~/Projekt/transcriber/venv
source ~/Projekt/transcriber/venv/bin/activate
pip install torch torchaudio speechbrain pyannote.audio

# pyannotes modell hämtas en gång med en token från huggingface.co
# (godkänn modellens villkor på sidan pyannote/speaker-diarization-3.1 först)
HF_TOKEN=hf_... python -c "from pyannote.audio import Pipeline; Pipeline.from_pretrained('pyannote/speaker-diarization-3.1', use_auth_token='$HF_TOKEN')"

# Engelska och flerspråkiga möten går via MLX
pip install mlx-whisper 'mlx==0.31.2'

Standardvägen är ~/Projekt/transcriber/venv; en annan pekas ut under ⌘, → Transkribering. Saknas pyannote delas rösterna med en reservmetod, som är märkbart sämre. Saknas miljön helt delas de inte alls, och appen säger det i mötesvyn.

mlx-whisper kräver mlx 0.31.2 på macOS 26.1. Nyare mlx faller mot Metal-kompilatorn utan att lämna någon utdata.

3. Ollama — frivilligt, för insikter och betydelsesökning

Under ett möte lyssnar appen efter sådant deltagarna behöver slå upp, och svarar ur kunskapsbanken. Bedömningen görs av en lokal modell via Ollama, så att allt som sägs granskas på datorn. Samma Ollama bäddar in materialet med bge-m3, vilket gör att sökningen förstår betydelse och inte bara ord.

brew install ollama
ollama serve &
ollama pull qwen3:8b     # 12 av 12 rätt utan falska larm i mätningen
ollama pull bge-m3       # betydelsesökningen; hybriden tog 11 av 12 mot 9 för ordsökning ensam

Utan Ollama fungerar allt annat. Insiktspanelen säger att ingen lokal modell nås, och sökningen går på ord.

5. Claude Code — frivilligt, för kopplade mappar

Ett projekt kan kopplas till mappar utanför kundmappen: källkod, ritningar, offerter. De indexeras inte; de genomsöks av en agent när du frågar. Agenten är Claude Code, som ska finnas installerad, och det den läser går till Anthropic.

6. Behörigheter

MikrofonKrävs. Ditt eget spår.
SkärminspelningKrävs för datorljudet. ScreenCaptureKit fångar bara ljud; ingen bild sparas.
KalenderMöten hos kunden, brief en kvart före, deltagarna som förslag när röster märks.
KontakterHämta personer ur adressboken, och lägga upp dem där på knapptryck.
Automatisering: MailSöka kundens mejl och hämta bilagor. Bara AppleScript, aldrig Full Disk Access.
PåminnelserLägga uppgifter från tavlan i Påminnelser, envägs.
NotiserNär ett möte är färdigbearbetat, och en kvart före nästa.

Alla ges i Systeminställningar → Integritet och säkerhet. Diagnosfliken visar vilka som är givna.
